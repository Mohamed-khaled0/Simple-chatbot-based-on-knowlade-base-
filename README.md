#  Simple Chatbot Based on Knowledge Base

This is a Python chatbot built using `sentence-transformers` and `tkinter`. It uses semantic similarity to respond to user questions from a predefined knowledge base. Great for beginner Python learners or as a mini assistant!

---

##  How to Run the Code

###  1. System Requirements
- Python 3.7+
- Internet connection (only required the first time to download the model)

---

###  2. Install Dependencies and run the app 

Install the necessary Python packages using pip:

```bash
pip install tk
pip install sentence-transformers
python chatbot.py
